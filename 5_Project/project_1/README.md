Egyptian League Management System

A simple C++ console application to manage Egyptian football teams and players.

Features

Add, display, update, and remove Teams.

Add, display, search, and remove Players.

Display players of a team sorted by salary.

Display teams ordered by average age.

Remove a team along with all its players.

How to Use

Compile using a C++ compiler:

g++ main.cpp -o league


Run the program:

./league


Follow the menu to manage teams and players.

Menu Options

Display Teams

Search Team by ID

Add Player

Remove Player

Display Players

Search Player by Name

Update Team Info

Display Teams (Ordered by Average Age)
